# 🤸 수학 체육올림픽 (초등 4학년 2학기)

**초등학교 4학년 2학기 수학 × 체육 융합 · 온몸 모션인식 기반 웹 교육 게임**

카메라 앞에 서서 **온몸을 움직이며** 즐기는 6종목 미니게임 모음입니다. 별도 설치 없이 웹 브라우저에서 바로 실행되며, 학생 개인이 60초 동안 각 종목의 기록에 도전합니다. 공간이 좁으면 태블릿 터치나 PC 마우스로도 똑같이 할 수 있습니다.

`motion-math-olympics`(2학년판) · `motion-math-olympics-1st`(1학년판) · `motion-math-olympics-3rd`(3학년판)과 같은 엔진·화면 구조를 쓰는 **시리즈 4번째 작품**입니다.

## 📖 소개

4학년 2학기 수학 6개 단원(분수의 덧셈과 뺄셈, 삼각형, 소수의 덧셈과 뺄셈, 사각형, 꺾은선그래프, 다각형)을 **4학년 체육과의 「동작 도전」(체조·매트·균형)과 「영역형 경쟁」(축구/농구형, 공간 침범 및 패스)** 영역과 묶어 6종목으로 재구성했습니다.

### 1~3학년판과 가장 크게 달라진 점 — 온몸을 씁니다

1~3학년판은 "태블릿을 책상에 놓고 앉아서 손만" 움직이는 전제였습니다. 4학년 체육은 **팔·다리의 각도**와 **몸통 회전**이 핵심이라, 이 학년판에서만 MediaPipe **PoseLandmarker(온몸 관절 인식)** 를 새로 얹었습니다.

- **종목 2**는 삼각형의 가장 큰 각을 **실제로 양팔로 만들어** 버팁니다 (관절 각도를 실시간 측정)
- 나머지 종목은 **양 손목**이 커서가 되어, 서서 팔을 뻗어 조작합니다

> 교실이 좁거나 카메라 각도가 안 나오면 **터치·마우스 모드**로 전환하세요. 종목 2의 각도 미션은 포인터를 끌면 양팔이 거울처럼 대칭으로 벌어지는 "가상 몸"으로 대체되어 동일하게 학습됩니다.

## ✨ 주요 특징

- **3가지 조작 방식**: 온몸 모션인식(카메라) / 터치 모드(태블릿) / 마우스 모드(PC)
- **자동 난이도 조절**: 3연속 정답이면 한 단계 올라가고, 2연속 실패면 내려가는 자동 조절 (⭐ 개수로 표시)
- **마리오파티식 3단 연출**: 규칙 카드 → `START!` 스탬프 → 결과 발표(드럼롤 · 메달 스탬프 · 기록 카운트업 · `NEW RECORD!` 리본 · 코인 정산)
- **코인 모으기**: 6종목이 하나의 목표로 묶입니다. 메달과 콤보에 따라 코인을 얻고 랜딩 화면에 총액이 표시됩니다
- **하이라이트 자동 저장**: 플레이 중 가장 잘한 순간의 사진과 3초 영상을 자동으로 만들어 기기에 저장 가능 (서버에는 저장되지 않음)
- **완전 반응형**: PC, 태블릿, 모바일 어떤 화면 크기·가로/세로 방향에서도 사용 가능
- **오프라인 친화적 설계**: AI 모델과 글꼴을 자체 서버에 내장해, 학교 네트워크 환경에서도 안정적으로 동작

## 💻 로컬에서 실행하기

바탕화면 경로에서는 로컬 서버가 권한 문제로 실행되지 않으므로, `/tmp`에 사본을 두고 서빙합니다.

```bash
rm -rf /tmp/mmo4 && mkdir -p /tmp/mmo4 && cp -R "/Users/mac/Desktop/클로드/motion-math-olympics-4th/." /tmp/mmo4/ && cd /tmp/mmo4 && python3 -m http.server 8794
```

브라우저에서 `http://localhost:8794` 접속. (카메라 권한이 필요한 모션인식 모드는 `localhost` 또는 HTTPS 환경에서만 정상 동작합니다.)

games/u2-triangle.html?level=3

## 🎨 설계 노트

### 마리오파티에서 가져온 것
- **미니게임은 3단 연출** — 규칙 카드로 "무엇을 하는 놀이인지" 먼저 보여주고, `START!` 스탬프가 쿵 찍힌 뒤 시작합니다
- **결과는 발표한다** — 통째로 툭 띄우지 않고 드럼롤 → 메달 스탬프 → 기록 카운트업 → `NEW RECORD!` 리본 → 코인 정산 순으로 하나씩
- **판정 등급 문구** — 콤보에 따라 `GOOD! → NICE! → GREAT! → PERFECT!` 가 통통 튀어오릅니다
- **피버 타임** — 3연속 정답이면 8초간 화면 테두리가 무지개로 달아오르고 코인이 2배가 됩니다. 피버 중에 틀리면 즉시 꺼져서, 잘하는 아이에게 "지키고 싶은 것"이 생깁니다
- **모든 것에 표정** — 분수를 든 친구, 굴러가는 다각형, 수비 블록까지 눈과 볼이 있습니다. 특히 종목 6은 **도형이 데굴데굴 굴러도 얼굴은 늘 정면**을 봅니다
- **응원 마스코트** — 화면 왼쪽 아래에 상주하며 정답이면 만세, 오답이면 갸웃합니다
- **둥근 손글씨 글꼴** — 화면 인상을 가장 크게 바꾼 요소입니다

### 체육과 융합을 "테마"가 아니라 "조작"에 넣었습니다
- **종목 1**: 패스 길에 수비수가 서 있으면 가로채기입니다. 값이 맞아도 **빈 공간이 열릴 때까지 기다려야** 합니다 — 영역형 경쟁의 핵심인 "공간 보기"가 그대로 판정에 들어갑니다
- **종목 2**: 평균대가 흔들려 삼각형도 같이 움직입니다. 각을 만든 뒤에도 **1.5초를 버텨야** 하고, 버티는 동안 관중 환호 게이지가 차오릅니다
- **종목 3**: 벽이 천천히 내려오는 동안 식을 풀어야 합니다. 문에 손을 넣으면 블록이 **부서져 흩날립니다**
- **종목 4**: 네 번째 점의 자리가 **사각형의 성질로만 정해집니다.** 평행사변형이면 마주 보는 변이 평행하고 길이가 같아야 하니 자리가 하나로 결정되고, 성질을 모르면 풀 수 없습니다. 오답 자리도 "사다리꼴은 되지만 평행사변형은 아닌 자리"처럼 실제로 헷갈리는 지점에만 둡니다
- **종목 5**: 정답을 짚으면 공이 그 자리에서 **골대로 날아갑니다**
- **종목 6**: 잡은 도형이 링에 들어가면 **곰돌이 심판이 점수판**을 듭니다

### 틀린 순간이 가장 잘 배우는 순간
오답이면 **정답이 무엇이었는지 1.1초 동안 초록으로 보여줍니다.** 종목 1은 완성된 식(`3/5 + 1/5 = 4/5`)이 뜨고, 나머지는 정답 자리에 초록 링과 이름표가 붙습니다.
3학년판은 "답을 알려주지 않는다"였지만, 4학년 내용(받아내림 있는 대분수 뺄셈, 자릿수 다른 소수)은 모르는 아이가 60초 내내 모른 채로 있게 됩니다. 문제가 매번 새로 생성되므로 외울 대상도 없습니다.

### 아이가 억울하지 않도록
- 새 문제가 뜬 뒤 **0.55초 동안은 입력을 받지 않습니다.** 손이 우연히 정답/오답 위에 놓여 있었다고 문제를 읽어보기도 전에 처리되면 억울하기 때문입니다
- 종목 1은 동료와 수비수가 **서로 다른 띠**에서 움직입니다. 겹쳐 있으면 엉뚱한 쪽이 판정되기 때문입니다
- 종목 2의 버티기 게이지는 인식이 한두 프레임 튀어도 **0으로 돌아가지 않고 천천히 샙니다**
- 종목 3은 문을 놓쳐도 남은 벽에서 만회할 수 있고, 판정은 정확한 타이밍이 아니라 "문 안에 손이 들어오면" 됩니다
- 종목 4는 손이 스치기만 해서는 판정되지 않습니다. **자리에 0.38초 머물러야** 결정되고, 머무는 동안 링이 차오릅니다 — 모션 모드에서 손이 지나가다 엉뚱한 자리를 고르는 일을 막습니다
- 종목 4는 앞 라운드에서 짚은 자리에 **손을 얹어 둔 채로 다음 문제가 시작되면, 손이 한 번 벗어나야** 판정을 시작합니다. 그러지 않으면 가만히 있어도 다음 문제가 저절로 찍힙니다
- 종목 6의 **모양 채우기는 조각을 놓쳐도 벌점이 없습니다.** 여러 개를 모아야 하는 미션이라 한 번 놓쳤다고 처음부터 다시 하면 너무 가혹하기 때문입니다

### 스스로 세고, 직접 겪어야 진짜 학습이 됩니다
- **종목 2**는 각도를 숫자로 알려주지 않습니다. 같은 길이 변의 눈금(=)과 직각 표시(⌐)만 찍어두고, 학생이 직접 보고 판단해야 합니다
- **종목 4**는 손을 올린 자리로 **대형을 미리 그려 보여줍니다.** 짚기 전에 모양을 확인할 수 있고, 완성되면 **평행 표시(≫)·같은 길이 눈금(=)·직각 표시(⌐)** 가 붙어 "왜 이게 평행사변형인지"가 눈에 보입니다
- **종목 6의 모양 채우기**는 실제로 빈틈없이 딱 맞아떨어지는 조합만 넣었습니다 — 정삼각형 2개 = 마름모, 정삼각형 3개 = 사다리꼴, 정사각형 2개 = 직사각형. 수학적으로 틀린 타일링을 보여주지 않기 위해서입니다
- **종목 5**는 세로 눈금 한 칸의 크기가 단계마다 바뀌고(1 → 2·5 → 0.5), 3단계에서는 물결선으로 아래를 생략한 그래프가 나옵니다. 눈금을 안 읽고 모양만 보면 틀립니다
